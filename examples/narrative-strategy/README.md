# narrative-strategy

Синтетический самостоятельный сценарий LUDOSCOPE. Файлы: `mechanic.json` — спецификация, `graph.json` — явные зависимости, `economy.json` — ограниченная модель ресурсов с seed 42.

Команды запуска, ожидаемые результаты и ограничения: [общая инструкция](../README.md).

`narrative.json` задаёт начальное состояние treaty=true, betrayal=false, war=false. Событие betray нарушает явный инвариант treaty=true; после него доступно событие war. Проверка возвращает цепочку нарушения без интерпретации литературного текста. Boolean-модель ограничена 100 состояниями и не проверяет мотивацию персонажей.

Автор должен выбрать: запретить предательство условиями, изменить эффект или официально пересмотреть инвариант. Инструмент не меняет канон. Для плейтеста сравните явно предупреждённое нарушение договора и отложенное раскрытие последствий; измеряйте понимание доступной информации и отдельно субъективное ощущение ответственности. Несогласие игрока с персонажем не равно логической ошибке мира.
