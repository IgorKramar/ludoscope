# card-roguelike

Синтетический самостоятельный сценарий LUDOSCOPE. Файлы: `mechanic.json` — спецификация, `graph.json` — явные зависимости, `economy.json` — ограниченная модель ресурсов с seed 42.

Команды запуска, ожидаемые результаты и ограничения: [общая инструкция](../README.md).

Опыт как гипотеза: выбор между дешёвым безопасным действием и более дорогим сильным эффектом. Различия последствий заданы в `choices`; инструмент не делает вывод о синергии только по названию карты. Для модели вероятность combo 0,5 задана явно; последовательность draw_mana → combo выполняется каждый tick. Это пример правил, а не агента, который выбирает стратегию.

Сравните прототипы фиксированной награды, случайной награды с предварительным раскрытием и обмена наград между категориями. Проверяйте разнообразие реально выбранных комбинаций и способность объяснить последствия. Добавьте формальные цены и выгоды для поиска доминирования; неизвестные контекстные преимущества должны оставаться ограничением вывода.
