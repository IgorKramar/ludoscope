# economic-tycoon

Синтетический самостоятельный сценарий LUDOSCOPE. Файлы: `mechanic.json` — спецификация, `graph.json` — явные зависимости, `economy.json` — ограниченная модель ресурсов с seed 42.

Команды запуска, ожидаемые результаты и ограничения: [общая инструкция](../README.md).

Модель в каждом tick выполняет `buy` → `produce` → `sell`, начиная с 10 money. Один завершённый цикл возвращает сырьё и товары к исходным значениям и прибавляет 1 money. За десять шагов получается 20 money. Статический анализ находит witness из трёх преобразований; симуляция проверяет его достижимость при конкретном стартовом запасе.

Ограничение money ≤ 15 намеренно нарушается на шаге 6. Нельзя назвать любую прибыль эксплойтом: сначала установите, что именно ограничивает канон экономики. Альтернативы для эксперимента: реальные накладные расходы, ограниченный спрос, плата за логистику. Сравнивайте время достижения цели, доступность альтернативных цепочек и чувствительность к цене продажи, не только итоговый баланс.
