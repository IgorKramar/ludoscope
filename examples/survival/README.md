# survival

Синтетический самостоятельный сценарий LUDOSCOPE. Файлы: `mechanic.json` — спецификация, `graph.json` — явные зависимости, `economy.json` — ограниченная модель ресурсов с seed 42.

Команды запуска, ожидаемые результаты и ограничения: [общая инструкция](../README.md).

Опыт как гипотеза: игрок планирует маршрут из-за ограниченной еды, затем получает время для более сложных решений после автоматизации. Сравните три варианта: ручное поддержание голода, контекстные затраты на экспедиции, автоматизированное питание. Следите за числом различающихся маршрутов, объяснениями решений и временем на обслуживание. Частые действия сами по себе не доказывают проблему.

Граф связывает hunger с погодой, производством и автоматизацией. Эти связи объявлены автором fixtures, а не выведены из игрового кода. В модели `farm` и `eat` образуют ресурсный цикл; формальная верхняя граница пищи 12 нарушается на шаге 8. Проверьте, является ли накопление целевой наградой или нарушением проектного ограничения, прежде чем предлагать исправление.
