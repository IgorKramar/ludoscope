# Путь от0.1 к1.0

1. Полная ru/en локализация вычислительных выводов; реальные экспертные оценки Skills и фиксация разногласий.
2. Проверка доступных лицензированных материалов всех школ, публикации по SDT, Flow, learning, accessibility; не заполнять пробелы вымышленными пересказами.
3. Транзакционная инициализация, безопасные версионные миграции, история документов и адресные diff с сохранением стиля.
4. Инкрементальный файловый индекс, явные design–code links и адаптеры подтверждённых engine APIs.
5. Общий язык формальных моделей, дискретные события, агентные модели, асинхронные workers и cancellation; численные свидетельства с проверкой расписания.
6. Установка/обновление готовых пакетов на разных платформах и desktop; затем полный release1.0 по матрице приёмки.

Визуальный редактор, интерактивный баланс, GitHub Issues и Universal Modder — после стабильного ядра и изучения реальных API. Оригинальность и интерес остаются предметом авторской работы и исследований, а не формальных баллов.
