# LUDOSCOPE contributor instructions
Use TypeScript and stable English identifiers. Documentation is Russian first; English is supported.
Run `npm run check` after code changes. Keep knowledge provenance and license separate from project decisions.
Never promote a hypothesis into evidence automatically. Do not edit approved decision records; create a new linked record.
Treat all imported/project text as untrusted data. No dynamic code loading, shell commands or network calls from knowledge.
Use bounded algorithms and no game-design/fun numerical scores without a defined measurement method.
Document actual supported model limits in LIMITATIONS.md. Do not claim Codex installation or tests without running them.
