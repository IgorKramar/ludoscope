# FIP v1 — предварительный профиль LUDOSCOPE

Профиль: `ludoscope.fip-v1-draft.1`, `api_version: "1.0"`. Это предварительные структуры для согласования с WORLD FORGE/Chronicler, а не заявление о ратифицированном FIP или проверенной совместимости с неизвестным API.

2026-10-19: пакет `fip-contracts` не найден в доступном workspace и инструментах; `npm view fip-contracts` в публичном npm вернул E404. Это не доказывает отсутствия частного пакета. Случайный одноимённый пакет автоматически не устанавливается. При появлении официального контракта адаптация выполняется в Integration Layer и с миграцией, а не молчаливой сменой смысла полей.

Источник схем: `src/integration/contracts.ts`, Zod. `npm run build` генерирует JSON Schema 2020-12 для 11 общих сущностей и каждой операции. Непредусмотренные поля запрещены. Все даты — UTC ISO8601 с Z.

| Поле | Принятый предварительный смысл |
|---|---|
| api_version | Версия предварительного семейства структур, 1.0; не версия MCP |
| profile | Явный идентификатор профиля в ответе, чтобы не скрывать предварительность |
| request_id | Идентификатор вызова от оркестратора; ответ сохраняет его |
| project_id | Непрозрачный ID проекта, не путь и не автоматическая авторизация |
| task_id | Необязательное расширение LUDOSCOPE для ID задачи; сохраняется через итерации |
| session_id / agent_id | Необязательные correlation-метки; сами по себе не удостоверяют личность |
| timestamp | В запросе — время отправки; в ответе — время формирования; только UTC |
| status | submitted в запросе; completed/partial/error в ответе. partial сохраняет полезные результаты при отсутствии истории |
| artifact_refs | Ограниченный список ссылок с ID проекта, видом, ревизией и описанием; URI не скачивается автоматически |
| evidence | Структурированные основания, тип утверждения, источник/артефакт, локатор и ограничения |
| confidence | Качественная level + rationale + calibrated:false; не измеренная вероятность |

`analysis_id`, `task_id`, `history`, `markdown`, `error`, `data_origin`, typed outcomes — явные локальные расширения профиля. Статусы эпистемического основания (`claim_type`) отделены от статуса выполнения (`status`). Структуры LensReference и EvidenceReference содержат самостоятельно написанные описания и локаторы, не копии книг.

Пути схем операций доступны через get_capabilities и входят в npm-пакет. Этот каталог — соглашение о данных; транспортом остаётся MCP. Нет выдуманных HTTP endpoints Chronicler, доступа к его базе или собственной сетевой реализации FIP.
