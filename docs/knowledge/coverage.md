# Неполнота исследовательского покрытия

Каталог расширяется по полю school, типам Theory/ResearchMethod и связям графа знаний. Следующие исследовательские направления предусмотрены как категории, но отсутствие верифицированных записей не скрывается. Перечень не является пересказом теорий или подтверждением универсального эффекта.

Популярность концепции или число источников не повышают её статус автоматически. Для новых записей сначала выполняется протокол KNOWLEDGE.md.
