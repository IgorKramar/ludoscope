## Проверка закреплённых исходников Hydrocraft

Ревизия: [`c2b72c30f52be23eb3d4d25d60d53a1974af6cea`](https://github.com/IgorKramar/HydrocraftReinvented/tree/c2b72c30f52be23eb3d4d25d60d53a1974af6cea).

Локально выполнены:

```sh
npm run pilot:hydrocraft -- --source /workspace/hydrocraft-readonly --output /tmp/ludoscope-hydrocraft-final
node dist/cli/index.js --project /workspace/hydrocraft-readonly trace examples/hydrocraft-pilot/source-traceability.json
```

Пять SHA-256 и размеров исходных файлов совпали, включая README. Manifest содержит пять привязок к четырём файлам реализации: все `current`; Git revision — `match`, `dirty:false`. После проверки `git status --porcelain` модового checkout пуст. Исходники мода не изменялись и в пакет не включены.

Общий результат трассировки — `partial`: утверждённая спецификация, автоматические тесты и плейтесты внешнего проекта в manifest не заявлены. Полнота не создаётся добавлением фиктивных связей.

Во всех четырёх сценариях — 18 семян, ноль нарушений заданных границ, сохранён учёт хлопка и оборота веретён на каждом шаге. Диагностическая модель без callback-возврата даёт одну ткань и ноль свободных веретён: неполный перенос правил меняет вывод.
