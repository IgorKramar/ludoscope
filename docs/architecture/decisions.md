# Architecture Decision Records

## ADR-001 — переносимый пакет, 2026-10-18, принято
Проблема: ТЗ зависит от меняющегося формата Codex. Проверены официальные guides plugins/skills/mcp-server и корневые JSON Schema Agent Plugins 1.0.0. Выбран корневой plugin.json + mcp.json + skills/. Старый README openai/plugins ещё описывает .codex-plugin; текущая документация считает его fallback. Не дублируем manifests. Пересмотр: изменение официальной схемы или несовместимость проверенного клиента.

## ADR-002 — вычисления, а не вторая LLM, принято
Core — чистые/ограниченные TypeScript-функции, Zod 4, SDK MCP 1.x, CLI commander. Codex формирует творческие альтернативы и связывает контекст. Никаких облачных зависимостей в runtime. JSON вместо SQLite: текущий набор мал; индекс создаётся лениво в памяти. Последствие: полнотекстовый поиск лексический, масштаб больших библиотек ограничен.

## ADR-003 — проектная запись только по намерению, принято
Анализ возвращает данные. init создаёт память, decision без --commit возвращает diff; commit создаёт неизменяемую запись. Атомарная публикация через hard link временного файла не заменяет существующее имя. Отклоняем traversal и символические ссылки. Не предполагаем враждебный процесс того же пользователя, меняющий каталоги одновременно; см. LIMITATIONS.

## ADR-004 — модель ограничена заданными правилами, принято
Базовый Systems Lab: дискретные ресурсные процессы с вероятностями, последовательность важна. Seed и полные параметры включены в результат. Поиск ресурсных циклов ограничен четырьмя применениями; это свидетельства потенциального роста, не доказательство бесконечной прибыли или интереса. FSM и Boolean narrative имеют отдельные контракты.

## ADR-005 — проверяемое происхождение, принято
Источники с недоступным содержанием остаются SOURCE_REQUIRED; библиографическая проверка не доказывает теорию. Оригинальные исследовательские методы — EXPERT_INFERENCE. Связанные знания могут образовывать циклы, Requires/DependsOn в design graph — нет. Утверждённые решения физически отделены от знаний.

## ADR-006 — независимый агентный API и предварительный FIP, принято 2026-10-19

Сохраняем существующее ядро и 24 MCP-операции. Добавляем Integration Layer с 16 строгими агентными операциями поверх тех же библиотек и пятью логическими engine-модулями. Это единый локальный процесс, без отдельной LLM и HTTP-сервера. JSON Schema и TypeScript выводятся из Zod.

Официальный `fip-contracts` недоступен в workspace/tools и публичном npm (E404). Вводим явно помеченный `ludoscope.fip-v1-draft.1`; не заявляем совместимость с неувиденным контрактом Chronicler. task_id — документированное локальное расширение. Официальные контракты подключаются через адаптацию и contract tests.

ChroniclerAdapter — подключаемый порт официального клиента хоста. Нет обращения к БД и выдуманных endpoints. Отсутствие истории не блокирует анализ; запись требует commit и положительной политики хоста. Автоматических повторов записи нет. Новые вычисления ограничены bounded_sync; асинхронные задания отложены до появления тяжёлых операций и отдельного job-контракта.

## ADR-007 — неизменяемые ссылки между итерациями, принято 2026-10-31

Проблема: форма JSON не гарантирует целостность ссылок. Объединение через Map могло скрыто заменить доказательство, а перенос анализа — потерять его артефакт. Гипотеза также могла сохранить ID при изменении цели автора.

Выбраны отдельная проверка отношений, объединение совпадающих неизменяемых записей и явный отказ при конфликте/переполнении. Автоматическая гипотеза идентифицируется контекстом и спецификацией; протокол эксперимента — полными заданными условиями. Исторические определения сохраняются. Доказательства знаний получают ID с учётом содержимого и версии.

Альтернатива — автоматически переписать ID конфликтующей записи. Отклонена: это изменило бы значение уже переданных ссылок без решения вызывающей стороны. Следствие: хост обязан использовать новый ID для новой ревизии артефакта и ограничивать объём истории.

Ошибки необязательной истории Chronicler дают partial; ошибки собственных входов вызывающей стороны отклоняются. Проверка ссылок не удостоверяет истинность содержимого.

## ADR-008 — воспроизводимый портфолио-кейс, принято 2026-10-31

Демонстрационный runner изолирует проектную память, использует реальные расчёты симулятора и сохраняет входы/выходы с SHA-256. Метрика эксперимента — число нарушений инварианта, чтобы среднее по траектории не скрывало нарушение границы.

GitHub Actions выполняет те же команды на Node.js 22/24, проверяет установленный пакет и сохраняет отчёты. Сценарий остаётся тестовым проектом; выводы о людях и реальном игровом пилоте не заявляются.
