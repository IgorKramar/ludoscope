# Участие в LUDOSCOPE

Спасибо за интерес к проекту. Для изменения кода используйте Node.js 22+ и отдельную ветку:

```sh
npm ci --ignore-scripts
npm run check
npm run demo
```

Прочитайте [AGENTS.md](AGENTS.md), [архитектуру](ARCHITECTURE.md) и [ограничения](LIMITATIONS.md). CLI и MCP должны переиспользовать ядро. Новый публичный интерфейс получает строгие входные/выходные схемы и содержательные контрактные тесты.

## Pull request

Опишите проблему, конкретное изменение поведения и способ проверки. Для исправления приложите минимальный воспроизводимый пример и регрессию. Изменения схем собираются через `npm run build`; проверьте diff в `schemas/` и `contracts/`. CI отклоняет незафиксированную генерацию.

Значимое дизайнерское решение не должно автоматически превращаться в «объективное правило». Сохраняйте различия между источником, интерпретацией, гипотезой и наблюдением.

## Знания и лицензии

Запись знаний должна указывать конкретный источник, проверенный фрагмент, степень уверенности и ограничения. Самостоятельные методы и линзы помечаются как интерпретации. Проверенная библиография не подтверждает прочтение содержания.

Не добавляйте коммерческие PDF, OCR, ключи доступа, частные игровые исходники или данные участников. Оригинальный код и самостоятельные материалы распространяются под MIT; права сторонних источников сохраняются. Подробности: [KNOWLEDGE.md](KNOWLEDGE.md).

## Отчёт об ошибке

Укажите версию LUDOSCOPE и Node.js, команду или MCP-операцию, ожидаемый и фактический результат. Приложите минимальные обезличенные входные данные. Для симуляций сохраните seed, модель и горизонт. Если проблема касается файлового доступа, опишите структуру каталогов без секретов.

## English

Use Node.js 22+, run `npm run check` and `npm run demo`, and describe the behavior change plus validation in the pull request. Keep public schemas reproducible. Do not redistribute commercial source books or promote hypotheses to verified observations.
