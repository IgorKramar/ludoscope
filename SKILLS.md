# Skills LUDOSCOPE

В комплект входят 17 Skills. Каждый `skills/<name>/SKILL.md` содержит назначение, условия, контекст, алгоритм, правила источников, выход, пример, пограничные случаи, завершение и связи. Основной язык русский; английский выбирается запросом или настройкой проекта. Фактическое обнаружение Skills зависит от поддерживаемой установки Agent Plugin; установка описана в README.

| Skill | Назначение |
|---|---|
| ludoscope | Маршрутизация режимов и аналитических профилей |
| concept-design | Концепции, аудитория, видение и принципы |
| mechanics-design | Действия, правила, переходы и назначение механики |
| systems-design | Зависимости, обратные связи и влияние изменений |
| experience-design | Предполагаемый опыт и player journey |
| balance-analysis | Метрики баланса и формальное сравнение вариантов |
| economy-design | Источники, стоки, обмен и условные эксплойты |
| progression-design | Освоение, prerequisites и раскрытие возможностей |
| narrative-design | Канон, события и согласованность состояний |
| emergence-analysis | Условные цепочки межсистемных взаимодействий |
| ai-behaviour-design | Наблюдения, цели и переходы игровых агентов |
| procedural-design | Валидность, выборки и воспроизводимость генерации |
| ux-review | Информационная иерархия, обучение и доступность |
| game-feel | Ввод, управление и обратная связь |
| playtest-design | Эксперименты и реальные наблюдения |
| game-audit | Аудит доступных артефактов с явным охватом |
| design-challenge | Состязательный поиск обходов и тупиков |

Начните с «LUDOSCOPE, помоги спроектировать …» или явно выберите соответствующий Skill средствами установленной среды Codex. Наличие файла Skill не означает, что он уже активирован в конкретном клиенте.

Центральный Skill читает только подходящую специализацию и релевантные знания. Codex формирует творческие альтернативы; MCP предоставляет проверяемый контекст и вычислимые результаты. Семь аналитических профилей последовательно рассматривают разные стороны задачи. Это не независимые агенты и не независимое экспертное подтверждение.

Все инструменты вызываются по фактической схеме MCP. При недоступном сервере Skill может выполнить явно обозначенный ручной анализ, но не заявляет результаты неисполненных проверок. Запись утверждённого решения требует явного выбора пользователя; исходники и канон не изменяются скрытно.

Рубрика `docs/ai-evaluations.json` предназначена для оценки ответов, ссылок, альтернатив и ограничений. Она не содержит выдуманных результатов пользовательских исследований и не доказывает творческое качество автоматически.
